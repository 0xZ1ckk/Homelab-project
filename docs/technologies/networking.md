Most of the networking side is emulated on a EVE-NG VM. It contains all of the routers and switches that make up the networking side of the lab. This decision was made because i wanted to use Cisco images and because i wanted to have control on layer 2 networking as well. In fact, in ESXi, the switching part is handled implicitly. The EVE-NG VM has several network adapters assigned to it that are used to connect it to the other VMs containing clients, servers and other types of hosts.
